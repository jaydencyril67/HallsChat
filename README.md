# HallsChat — Frontend

A mobile-first messaging UI foundation for HallsChat, using a deep burgundy and crimson identity.

## Stack
- React + TypeScript + Vite
- Lucide icons
- Responsive desktop and mobile layouts

## Run locally
```bash
npm install
npm run dev
```

## Current status
This is the first visual prototype. Conversations and message sending are local preview state only; there is no live account system or real message delivery yet. The backend will be developed in the separate `HallsChats` repository.

## Build
```bash
npm run build
```
